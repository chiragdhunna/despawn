# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Despawn, please report it privately through [GitHub Security Advisories](https://github.com/chiragdhunna/despawn/security/advisories) on this repository.

Please do not report security vulnerabilities through public GitHub issues or discussions.

## Response Commitments

Despawn is an open-source project maintained on a best-effort basis. We do not make promises regarding response times or resolution SLAs beyond best effort.
